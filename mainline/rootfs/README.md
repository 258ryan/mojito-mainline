# Superseded

These files were copied onto the phone by hand before the device package existed. The maintained versions now live in
the device package (`device-xiaomi-mojito`, `hexagonrpcd-mojito`; private repo `258ryan/mojito-device`), which also
replaced the root-run hexagonrpcd in `etc/init.d/mojito-wifi` with a `hexagonrpcd-mojito` service running as the
`fastrpc` user. Keep these only as a record; do not install them over the packaged files.
